# tongxue-skills-docs-init

一个 Vibe Coding 开工前用的 AI 技能：把一份已确认的项目规划（SPEC.md）交给它，它会在项目文件夹里自动生成一整套 AI 开发需要的文档，让 AI 写代码时有规矩可依、有进度可查、换窗口也能无缝交接。

## 它会生成什么

```
项目文件夹/
├── AGENTS.md          AI 开发须知：AI 每次开工必读的规矩
├── README.md          项目入口说明书（给人看）
├── .gitignore         按项目类型排除密钥、本地配置等文件
└── docs/
    ├── SPEC.md            你的项目规划，原样保存，一字不改
    ├── ARCHITECTURE.md    技术架构、代码文件夹结构与数据设计
    ├── ROADMAP.md         分阶段任务清单与验收标准
    └── PROGRESS.md        进度与交接记录（空骨架）
```

## 怎么用

1. 把 `tongxue-skills-docs-init` 文件夹放进你的 AI 开发工具的技能目录（或直接拖进对话）
2. 在项目文件夹里，把技能和项目规划一起拖进对话，发一句：
   > 使用这个技能，初始化项目文档
3. AI 会先报告项目类型和要创建的文件清单，你确认后它才动手
4. 生成完后，按它给的【待确认】清单补齐规划里缺的内容

## 设计原则

- **规划不被改动**：SPEC.md 原样保存，其他文档都在它的基础上展开
- **不编造**：规划里没写的内容一律标【待确认】，不让 AI 脑补
- **不过度规划**：小项目没必要写的部分就留空并说明原因
- **不覆盖文件**：遇到已有同名文件，先停下来问你
- **先确认再动手**：动手前列出完整清单，等你确认

## 生成的 AGENTS.md 会约束 AI 做到

- 开工前按顺序读文档，发现代码和文档不一致先报告
- 每个阶段开工前，先说清楚需不需要你手动操作（如申请密钥），不准用假密钥顶着
- 一次只做一个任务，只改相关文件，代码按模块拆分
- 密钥只放服务端，不准写进代码
- 每次改动都要更新 PROGRESS.md，并写上精确到分钟的时间
- 对话太长时主动提醒你换新窗口，并给出可一键复制的交接提示词

## 适用项目

目前内置微信小程序、Next.js、Node.js、Python 的 .gitignore 规则和专属禁止事项，其他类型的项目也能用，只是要自己补充专属规则。
